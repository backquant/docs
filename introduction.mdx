## Available data

The API covers seven categories of market data:

| Category | Description |
| --- | --- |
| **GEX** | Gamma exposure analysis — strike profiles, expiry profiles, levels, and history |
| **Perpetuals** | Funding rates, open interest, volume, long/short ratio, CVD, and Coinbase premium |
| **Options** | IV surface, term structure, skew, expected move, and volatility risk premium |
| **Macro** | Treasury yields, credit spreads, VIX, PMI, CPI, PCE, liquidity, and more |
| **Equities** | Market breadth, equity/bond ratio, cyclicals vs. defensives, cap and style ratios |
| **ETFs** | BTC, ETH, SOL, and XRP ETF flows, AUM, premiums, and Grayscale data |
| **Liquidation** | Liquidation heatmaps and distributions |
