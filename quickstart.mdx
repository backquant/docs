This guide walks you through making your first request to the BackQuant API.

<Steps>
  <Step title="Get your API key">
    Go to the [BackQuant Dashboard](https://backquant.com/dashboard) and copy your API key.

    Your key looks like this:

    ```
    bq_live_your_api_key_here
    ```
  </Step>

  <Step title="Make your first request">
    Call the `/gex/levels` endpoint to retrieve current GEX levels. Replace `YOUR_API_KEY` with your actual key.

    ```bash
    curl https://api.backquant.com/v1/gex/levels \
      -H "X-API-Key: YOUR_API_KEY"
    ```
  </Step>

  <Step title="Handle the response">
    Every API response uses the same envelope format. A successful response looks like this:

    ```json
    {
      "success": true,
      "data": {
        "zero_gamma": 5200.0,
        "call_wall": 5400.0,
        "put_wall": 5000.0,
        "major_positive": 5300.0,
        "major_negative": 4900.0
      },
      "meta": {
        "timestamp": "2026-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    Check `success` before reading `data`. If `success` is `false`, read the `error` object instead. See [Errors](/concepts/errors) for a full list of error codes.
  </Step>
</Steps>
