---
title: "ETF flows"
description: "Daily net flow data for spot crypto ETFs, showing institutional buying and selling pressure across BTC, ETH, SOL, XRP, and Hong Kong BTC products."
---

ETF flow data captures the net amount of capital entering or leaving spot crypto ETFs each day. Consistent inflows signal sustained institutional demand; outflows indicate redemption pressure or risk-off rotation. Use flows in combination with price action to distinguish between demand-driven rallies and liquidity-driven ones.

All endpoints require a valid `X-API-Key` header.

<Tabs>
  <Tab title="BTC">
    ## GET /etf/btc/flows

    Returns daily net flow data for US-listed spot Bitcoin ETFs, aggregated across all issuers (BlackRock, Fidelity, ARK, and others).

    **Request**

    ```bash
    curl https://api.backquant.com/v1/etf/btc/flows \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Query parameters**

    <ParamField query="limit" type="number" default="1">
      Number of daily data points to return. Returns the most recent day by default.
    </ParamField>

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "date": "2024-01-15",
        "net_flow_usd": 625400000,
        "inflow_usd": 831200000,
        "outflow_usd": 205800000,
        "issuers": [
          { "name": "iShares (BlackRock)", "net_flow_usd": 412300000 },
          { "name": "Fidelity", "net_flow_usd": 188600000 },
          { "name": "ARK 21Shares", "net_flow_usd": 24500000 }
        ]
      },
      "meta": {
        "timestamp": "2024-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    <ResponseField name="data.date" type="string">
      Trade date for this flow reading (YYYY-MM-DD).
    </ResponseField>
    <ResponseField name="data.net_flow_usd" type="number">
      Net capital flow across all BTC ETFs in USD. Positive = net inflow; negative = net outflow.
    </ResponseField>
    <ResponseField name="data.inflow_usd" type="number">
      Total gross inflows across all BTC ETFs in USD.
    </ResponseField>
    <ResponseField name="data.outflow_usd" type="number">
      Total gross outflows (redemptions) across all BTC ETFs in USD.
    </ResponseField>
    <ResponseField name="data.issuers" type="array">
      Per-issuer breakdown of net flows. Each object contains `name` (string) and `net_flow_usd` (number).
    </ResponseField>
  </Tab>
