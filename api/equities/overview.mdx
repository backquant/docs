---
title: "Equities"
description: "Stock market breadth, relative value, and sector rotation signals derived from major US equity indices."
---

The equities endpoints give you macro-level signals about the health and composition of equity markets — from the percentage of stocks trading above key moving averages to relative performance ratios between asset classes and sectors. Use these signals alongside price data to assess broad market conditions and identify rotation opportunities.

All endpoints in this group require a valid `X-API-Key` header.

<AccordionGroup>
  <Accordion title="GET /equities/ma-breadth — Moving average breadth">
    Returns the percentage of S&P 500 constituent stocks currently trading above their 50-day and 200-day moving averages.

    Breadth measures how many individual stocks are participating in a move. A rising index with declining breadth — fewer stocks above their moving averages — is a divergence that often precedes corrections. Use this endpoint to confirm or question trend strength.

    **Request**

    ```bash
    curl https://api.backquant.com/v1/equities/ma-breadth \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Query parameters**

    <ParamField query="limit" type="number" default="1">
      Number of historical data points to return. Defaults to the most recent reading.
    </ParamField>

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "timestamp": "2024-01-15T00:00:00Z",
        "above_ma50": 62.4,
        "above_ma200": 71.8
      },
      "meta": {
        "timestamp": "2024-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    <ResponseField name="data.timestamp" type="string">
      ISO 8601 date for this breadth reading.
    </ResponseField>
    <ResponseField name="data.above_ma50" type="number">
      Percentage of S&P 500 stocks trading above their 50-day moving average.
    </ResponseField>
    <ResponseField name="data.above_ma200" type="number">
      Percentage of S&P 500 stocks trading above their 200-day moving average.
    </ResponseField>
  </Accordion>

  <Accordion title="GET /equities/equity-bond-ratio — Equity/bond ratio">
    Returns the ratio of equity prices (SPY) to bond prices (TLT), representing the relative performance of risk assets versus safe havens.

    A rising equity/bond ratio signals a risk-on environment where investors prefer equities over Treasuries. A falling ratio indicates a flight to safety. Use this alongside funding rates and volatility data to confirm macro regime shifts.

    **Request**

    ```bash
    curl https://api.backquant.com/v1/equities/equity-bond-ratio \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Query parameters**

    <ParamField query="limit" type="number" default="1">
      Number of historical data points to return.
    </ParamField>

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "timestamp": "2024-01-15T00:00:00Z",
        "ratio": 4.87,
        "equity_price": 475.32,
        "bond_price": 97.56,
        "trend": "rising"
      },
      "meta": {
        "timestamp": "2024-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    <ResponseField name="data.ratio" type="number">
      Current SPY/TLT price ratio.
    </ResponseField>
    <ResponseField name="data.equity_price" type="number">
      Latest SPY price used in the ratio calculation.
    </ResponseField>
    <ResponseField name="data.bond_price" type="number">
      Latest TLT price used in the ratio calculation.
    </ResponseField>
    <ResponseField name="data.trend" type="string">
      Short-term direction of the ratio: `rising`, `falling`, or `neutral`.
    </ResponseField>
  </Accordion>

  <Accordion title="GET /equities/cyclicals-defensives — Cyclicals vs defensives rotation">
    Returns the relative performance ratio of cyclical sectors (XLY, XLB, XLI) versus defensive sectors (XLU, XLP, XLV).

    Cyclical sectors outperform when the economy is expanding and risk appetite is high. Defensive sectors hold up when growth is slowing or uncertainty is elevated. Tracking this rotation helps you gauge whether institutional money is positioning for growth or protection.

    **Request**

    ```bash
    curl https://api.backquant.com/v1/equities/cyclicals-defensives \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Query parameters**

    <ParamField query="limit" type="number" default="1">
      Number of historical data points to return.
    </ParamField>

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "timestamp": "2024-01-15T00:00:00Z",
        "ratio": 1.14,
        "cyclicals_return_30d": 3.82,
        "defensives_return_30d": -0.61,
        "regime": "risk_on"
      },
      "meta": {
        "timestamp": "2024-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    <ResponseField name="data.ratio" type="number">
      Cyclicals-to-defensives price ratio. Values above 1 indicate cyclicals outperforming.
    </ResponseField>
    <ResponseField name="data.cyclicals_return_30d" type="number">
      30-day return of the cyclical sector basket, as a percentage.
    </ResponseField>
    <ResponseField name="data.defensives_return_30d" type="number">
      30-day return of the defensive sector basket, as a percentage.
    </ResponseField>
    <ResponseField name="data.regime" type="string">
      Inferred regime based on the ratio: `risk_on`, `risk_off`, or `neutral`.
    </ResponseField>
  </Accordion>

  <Accordion title="GET /equities/large-small-cap — Large vs small cap ratio">
    Returns the ratio of large-cap equity performance (SPY) to small-cap performance (IWM).

    Small caps tend to lead in strong bull markets driven by domestic growth, while large caps hold up better during uncertainty or dollar strength. A sustained divergence between the two often signals regime change or liquidity stress. This ratio is useful as a leading indicator of risk appetite and economic momentum.

    **Request**

    ```bash
    curl https://api.backquant.com/v1/equities/large-small-cap \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Query parameters**

    <ParamField query="limit" type="number" default="1">
      Number of historical data points to return.
    </ParamField>

    **Response**

    ```json
      "data": {
        "timestamp": "2024-01-15T00:00:00Z",
        "ratio": 2.46,
        "large_cap_price": 475.32,
        "small_cap_price": 193.22,
        "trend": "large_cap_leading"
      },
      "meta": {
        "timestamp": "2024-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    <ResponseField name="data.ratio" type="number">
      SPY/IWM price ratio. Higher values indicate large caps outperforming.
    </ResponseField>

  </Accordion>

  <Accordion title="GET /equities/growth-value — Growth vs value ratio">
    Returns the relative performance ratio of growth stocks (QQQ) versus value stocks (IWD).

    Growth outperforms in low-rate, high-liquidity environments; value tends to lead when rates rise or the economy is early-cycle. The growth/value ratio is a useful proxy for monetary conditions and can confirm or contradict signals from yield data. Use it alongside the equity/bond ratio for a fuller picture of equity market positioning.

    **Request**

    ```bash
    curl https://api.backquant.com/v1/equities/growth-value \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Query parameters**

    <ParamField query="limit" type="number" default="1">

    ```json
        "ratio": 2.08,

        "value_price": 194.31,

      },
      "meta": {
        "timestamp": "2024-01-15T12:00:00Z",
        "version": "1.0"
      }
    }
    ```

    <ResponseField name="data.ratio" type="number">
      QQQ/IWD price ratio. Higher values indicate growth outperforming value.

    <ResponseField name="data.growth_price" type="number">
