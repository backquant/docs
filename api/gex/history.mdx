---
title: "GEX history"
description: "Returns a time series of aggregate gamma exposure, letting you track how the overall GEX regime has evolved over time."
---

The GEX history endpoint returns a dated series of total gamma exposure and key level snapshots. Use it to chart how the GEX regime has shifted — from positive to negative and back — alongside price action, to understand how past regime transitions corresponded to volatility or trend changes. It also powers backtests and quantitative strategies that incorporate GEX as a signal.

```
GET /gex/history
```

## Query parameters

<ParamField query="symbol" type="string" required>
  The underlying asset symbol. Examples: `BTC`, `ETH`, `SOL`.
</ParamField>

<ParamField query="start_date" type="string">
  Start of the date range in `YYYY-MM-DD` format. Defaults to 30 days before `end_date`.
</ParamField>

<ParamField query="end_date" type="string">
  End of the date range in `YYYY-MM-DD` format. Defaults to the most recent available date.
</ParamField>

<ParamField query="interval" type="string" default="1d">
  Data granularity. Accepted values: `1d` (daily). Additional intervals may be available depending on your subscription tier.
</ParamField>

## Request example

```bash
curl "https://api.backquant.com/v1/gex/history?symbol=BTC&start_date=2024-01-01&end_date=2024-01-15" \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Response fields

<ResponseField name="success" type="boolean" required>
  `true` when the request succeeded.
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="symbol" type="string">
      The requested asset symbol.
    </ResponseField>
    <ResponseField name="interval" type="string">
      The data granularity used.
    </ResponseField>
    <ResponseField name="history" type="object[]">
      Array of daily GEX snapshots, ordered by date ascending.
      <Expandable title="history entry properties">
        <ResponseField name="date" type="string">
          Snapshot date in `YYYY-MM-DD` format.
        </ResponseField>
        <ResponseField name="spot_price" type="number">
          Spot price of the underlying on this date.
        </ResponseField>
        <ResponseField name="total_gex" type="number">
          Aggregate net GEX across all strikes and expiries, in USD notional. Negative values indicate a negative gamma regime on this date.
        </ResponseField>
        <ResponseField name="regime" type="string">
          Gamma regime for this date. `"positive"` when `total_gex` is positive; `"negative"` when it is negative.
        </ResponseField>
        <ResponseField name="flip_level" type="number">
          The GEX flip price on this date.
        </ResponseField>
        <ResponseField name="positive_gamma_wall" type="number">
          Strike with the highest positive GEX on this date.
        </ResponseField>
        <ResponseField name="negative_gamma_wall" type="number">
          Strike with the largest negative GEX on this date.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  <Expandable title="properties">
    <ResponseField name="timestamp" type="string">
      ISO 8601 timestamp of when the response was generated.
    </ResponseField>
    <ResponseField name="version" type="string">
      API version.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  Historical data availability depends on your subscription tier. If your requested `start_date` predates your plan's data window, the API returns data from the earliest available date without an error.
</Note>
