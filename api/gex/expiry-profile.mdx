---
title: "Expiry profile"
description: "Returns gamma exposure broken down by option expiry date, showing how GEX is distributed across the term structure."
---

The expiry profile lets you see how much gamma is concentrated in each expiry bucket. Nearby expiries (especially weekly or daily) carry the highest per-dollar gamma impact because their options are most sensitive to spot moves. Far-dated expiries carry less gamma per dollar of notional but still influence the overall regime. Use this endpoint to understand whether current GEX is dominated by short-dated positions — which can unwind quickly — or distributed across the term structure.

```
GET /gex/expiry-profile
```

## Query parameters

<ParamField query="symbol" type="string" required>
  The underlying asset symbol. Examples: `BTC`, `ETH`, `SOL`.
</ParamField>

<ParamField query="date" type="string">
  Date for which to return the expiry profile, in `YYYY-MM-DD` format. Defaults to the most recent available snapshot.
</ParamField>

## Request example

```bash
curl "https://api.backquant.com/v1/gex/expiry-profile?symbol=BTC&date=2024-01-15" \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Response fields

<ResponseField name="success" type="boolean" required>
  `true` when the request succeeded.
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="properties">
    <ResponseField name="symbol" type="string">
      The requested asset symbol.
    </ResponseField>
    <ResponseField name="date" type="string">
      The date of the snapshot in `YYYY-MM-DD` format.
    </ResponseField>
    <ResponseField name="spot_price" type="number">
      Spot price of the underlying at the time of the snapshot.
    </ResponseField>
    <ResponseField name="total_gex" type="number">
      Aggregate GEX across all expiries, in USD notional.
    </ResponseField>
    <ResponseField name="expiries" type="object[]">
      Array of per-expiry GEX entries, ordered by expiry date ascending.
      <Expandable title="expiry object properties">
        <ResponseField name="expiry_date" type="string">
          The option expiry date in `YYYY-MM-DD` format.
        </ResponseField>
        <ResponseField name="dte" type="number">
          Days to expiry from the snapshot date.
        </ResponseField>
        <ResponseField name="gex" type="number">
          Net gamma exposure from options expiring on this date, in USD notional.
        </ResponseField>
        <ResponseField name="gex_pct" type="number">
          This expiry's GEX as a percentage of `total_gex`.
        </ResponseField>
        <ResponseField name="call_gex" type="number">
          Gamma exposure from call options expiring on this date.
        </ResponseField>
        <ResponseField name="put_gex" type="number">
          Gamma exposure from put options expiring on this date. Always negative or zero.
        </ResponseField>
        <ResponseField name="open_interest" type="number">
          Total open interest across all strikes for this expiry, in contracts.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  <Expandable title="properties">
    <ResponseField name="timestamp" type="string">
      ISO 8601 timestamp of when the response was generated.
    </ResponseField>
    <ResponseField name="version" type="string">
      API version.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
  High concentration in near-dated expiries (low DTE) signals that a significant portion of current GEX will roll off soon. Monitor `gex_pct` for the nearest expiries — when they represent more than 40–50% of total GEX, expect a regime shift as that expiry passes.
</Note>
