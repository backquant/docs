---
title: "Volume"
description: "Retrieve trading volume for perpetual futures contracts across exchanges."
---

The `/perps/volume` endpoint returns trading volume for perpetual futures contracts. High volume on directional moves adds conviction; high volume on consolidation can signal distribution or accumulation. Use this endpoint to confirm breakouts, identify unusual activity spikes, and compare relative activity across exchanges.

## Endpoint

```
GET https://api.backquant.com/v1/perps/volume
```

## Request

```bash
curl "https://api.backquant.com/v1/perps/volume?symbol=BTC&exchange=binance&timeframe=1d&limit=90" \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Parameters

<ParamField query="symbol" type="string" required>
  Asset ticker. Examples: `BTC`, `ETH`, `SOL`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange to query. Examples: `binance`, `bybit`, `okx`. Omit to aggregate across all supported exchanges.
</ParamField>

<ParamField query="timeframe" type="string">
  Data resolution. Common values: `1h`, `4h`, `1d`. Defaults to `1d`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of data points to return. Defaults to `90`. Maximum: `500`.
</ParamField>

## Response fields

<ResponseField name="data.symbol" type="string">
  The asset ticker that was queried.
</ResponseField>

<ResponseField name="data.exchange" type="string">
  The exchange the volume data originates from.
</ResponseField>

<ResponseField name="data.volume" type="array">
  Array of volume snapshots ordered by timestamp descending.
</ResponseField>

<ResponseField name="data.volume[].timestamp" type="string">
  ISO 8601 timestamp for the period.
</ResponseField>

<ResponseField name="data.volume[].volume_usd" type="number">
  Total traded volume for the period denominated in USD.
</ResponseField>

<ResponseField name="data.volume[].volume_coin" type="number">
  Total traded volume for the period denominated in the underlying asset.
</ResponseField>

<ResponseField name="data.volume[].buy_volume_usd" type="number">
  Taker buy volume for the period in USD.
</ResponseField>

<ResponseField name="data.volume[].sell_volume_usd" type="number">
  Taker sell volume for the period in USD.
</ResponseField>

<ResponseField name="meta.timestamp" type="string">
  ISO 8601 timestamp of when the response was generated.
</ResponseField>

<ResponseField name="meta.version" type="string">
  API version.
</ResponseField>
