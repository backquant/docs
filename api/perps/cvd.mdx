---
title: "CVD"
description: "Retrieve the cumulative volume delta for perpetual futures to measure net buying and selling pressure."
---

The `/perps/cvd` endpoint returns the Cumulative Volume Delta (CVD) — the running sum of taker buy volume minus taker sell volume. When price rises but CVD falls (divergence), sellers are absorbing liquidity and the move may be weakening. When CVD and price trend together, the move has directional conviction. Use CVD to validate momentum, spot exhaustion, and time reversals.

## Endpoint

```
GET https://api.backquant.com/v1/perps/cvd
```

## Request

```bash
curl "https://api.backquant.com/v1/perps/cvd?symbol=BTC&exchange=binance&timeframe=1h&limit=168" \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Parameters

<ParamField query="symbol" type="string" required>
  Asset ticker. Examples: `BTC`, `ETH`, `SOL`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange to query. Examples: `binance`, `bybit`, `okx`. Omit to aggregate across all supported exchanges.
</ParamField>

<ParamField query="timeframe" type="string">
  Data resolution for delta calculation. Common values: `15m`, `1h`, `4h`, `1d`. Defaults to `1h`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of data points to return. Defaults to `168` (one week at 1h). Maximum: `1000`.
</ParamField>

## Response

```json
{
  "success": true,
  "data": {
    "symbol": "BTC",
    "exchange": "binance",
    "cvd": [
      {
        "timestamp": "2024-01-15T12:00:00Z",
        "delta": 124500000,
        "cumulative_delta": 2841200000,
        "price": 42850.12
      },
      {
        "timestamp": "2024-01-15T11:00:00Z",
        "delta": -87300000,
        "cumulative_delta": 2716700000,
        "price": 42610.44
      }
    ]
  },
  "meta": {
    "timestamp": "2024-01-15T12:00:00Z",
    "version": "1.0"
  }
}
```

## Response fields

<ResponseField name="data.symbol" type="string">
  The asset ticker that was queried.
</ResponseField>

<ResponseField name="data.exchange" type="string">
  The exchange the CVD data originates from.
</ResponseField>

<ResponseField name="data.cvd" type="array">
  Array of CVD data points ordered by timestamp descending.
</ResponseField>

<ResponseField name="data.cvd[].timestamp" type="string">
  ISO 8601 timestamp for the period.
</ResponseField>

<ResponseField name="data.cvd[].delta" type="number">
  Net volume delta for the period (taker buy volume minus taker sell volume) in USD. Positive values indicate net buying pressure; negative values indicate net selling pressure.
</ResponseField>

<ResponseField name="data.cvd[].cumulative_delta" type="number">
  Running cumulative sum of all period deltas in USD, resetting at the start of the returned window.
</ResponseField>

<ResponseField name="data.cvd[].price" type="number">
  Asset price at the close of the period in USD. Useful for divergence analysis alongside the CVD.
</ResponseField>

<ResponseField name="meta.timestamp" type="string">
  ISO 8601 timestamp of when the response was generated.
</ResponseField>

<ResponseField name="meta.version" type="string">
  API version.
</ResponseField>
