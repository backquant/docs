---
title: "Long/short ratio"
description: "Retrieve the ratio of long to short positions held by traders on perpetual futures markets."
---

The `/perps/long-short-ratio` endpoint returns the proportion of accounts or positions that are net long versus net short. Extreme readings — particularly when most retail traders are positioned on one side — often precede counter-trend moves. Use this endpoint to identify crowded trades, assess market sentiment, and look for contrarian signals.

## Endpoint

```
GET https://api.backquant.com/v1/perps/long-short-ratio
```

## Request

```bash
curl "https://api.backquant.com/v1/perps/long-short-ratio?symbol=BTC&exchange=binance&timeframe=1d&limit=90" \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Parameters

<ParamField query="symbol" type="string" required>
  Asset ticker. Examples: `BTC`, `ETH`, `SOL`.
</ParamField>

<ParamField query="exchange" type="string">
  Exchange to query. Examples: `binance`, `bybit`, `okx`. Omit to aggregate across all supported exchanges.
</ParamField>

<ParamField query="timeframe" type="string">
  Data resolution. Common values: `1h`, `4h`, `1d`. Defaults to `1d`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of data points to return. Defaults to `90`. Maximum: `500`.
</ParamField>

```json
{
  "success": true,
  "data": {

```

## Response fields

<ResponseField name="data.symbol" type="string">
  The asset ticker that was queried.
</ResponseField>

<ResponseField name="data.exchange" type="string">
  The exchange the data originates from.
</ResponseField>

<ResponseField name="data.long_short_ratio" type="array">
  Array of long/short ratio snapshots ordered by timestamp descending.
</ResponseField>

<ResponseField name="data.long_short_ratio[].timestamp" type="string">
  ISO 8601 timestamp of the snapshot.
</ResponseField>

<ResponseField name="data.long_short_ratio[].ratio" type="number">
  Ratio of long positions to short positions. A value of `1.42` means there are 1.42 long positions for every 1 short position.
</ResponseField>

<ResponseField name="data.long_short_ratio[].long_pct" type="number">
  Percentage of accounts or positions that are net long.
</ResponseField>

<ResponseField name="data.long_short_ratio[].short_pct" type="number">
  Percentage of accounts or positions that are net short.
</ResponseField>

<ResponseField name="meta.timestamp" type="string">
  ISO 8601 timestamp of when the response was generated.
</ResponseField>

<ResponseField name="meta.version" type="string">
  API version.
</ResponseField>
