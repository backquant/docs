---
title: "Market index"
description: "Retrieve a composite index score reflecting overall crypto market conditions."
---

The `/market/index` endpoint returns a composite market conditions index that aggregates signals across price action, momentum, volatility, and cross-asset flows. Use it to get a high-level read on whether the market is in a risk-on or risk-off regime before sizing positions or adjusting strategy parameters.

## Endpoint

```
GET https://api.backquant.com/v1/market/index
```

## Request

```bash
curl https://api.backquant.com/v1/market/index \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Parameters

<ParamField query="timeframe" type="string">
  The resolution of returned data points. Common values: `1h`, `4h`, `1d`. Defaults to `1d`.
</ParamField>

<ParamField query="limit" type="integer">
  Number of data points to return. Defaults to `90`. Maximum: `365`.
</ParamField>

## Response

```json
{
  "success": true,
  "data": {
    "index": [
      {
        "timestamp": "2024-01-15T00:00:00Z",
        "value": 62.4,
        "regime": "risk-on",
        "components": {
          "momentum": 68.1,
          "volatility": 41.2,
          "breadth": 71.5,
          "flow": 58.8
        }
      },
      {
        "timestamp": "2024-01-14T00:00:00Z",
        "value": 57.9,
        "regime": "neutral",
        "components": {
          "momentum": 61.3,
          "volatility": 49.7,

    "timestamp": "2024-01-15T12:00:00Z",

```

## Response fields

<ResponseField name="data.index" type="array">
  Array of index snapshots ordered by timestamp descending.
</ResponseField>

<ResponseField name="data.index[].timestamp" type="string">
  ISO 8601 timestamp for the data point.
</ResponseField>

<ResponseField name="data.index[].value" type="number">
  Composite index score from 0 to 100. Higher values indicate stronger risk-on conditions.
</ResponseField>

<ResponseField name="data.index[].regime" type="string">
  Categorical market regime derived from the index value. One of `risk-on`, `neutral`, or `risk-off`.
</ResponseField>

<ResponseField name="data.index[].components" type="object">
  Sub-scores for each component that feeds into the composite index.
</ResponseField>

<ResponseField name="data.index[].components.momentum" type="number">
  Momentum component score (0–100).
</ResponseField>

<ResponseField name="data.index[].components.volatility" type="number">
  Volatility component score (0–100). Lower values indicate lower volatility, contributing positively to the index.
</ResponseField>

<ResponseField name="data.index[].components.breadth" type="number">
  Market breadth component score (0–100).
</ResponseField>

<ResponseField name="data.index[].components.flow" type="number">
  Cross-asset flow component score (0–100).
</ResponseField>

<ResponseField name="meta.timestamp" type="string">
  ISO 8601 timestamp of when the response was generated.
</ResponseField>

<ResponseField name="meta.version" type="string">
  API version.
</ResponseField>
