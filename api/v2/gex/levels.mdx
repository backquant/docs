---
title: "GEX levels"
openapi: "GET /gex/levels"
---

Composable HVL / call wall / put support / 0DTE levels in one call. Use
`?include=` to opt into max-pain, expected move, ranked top-10, gamma
flip zones, spot, candles.

Default **`positioning=flow`**. Pass `?positioning=std` for textbook
call/put OI signing. See [Positioning](/concepts/positioning).
