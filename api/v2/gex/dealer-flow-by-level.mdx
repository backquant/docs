---
title: "Dealer flow by level"
openapi: "GET /gex/dealer-flow/by-level"
---

Expected cumulative dealer hedge dollars if spot walks from the current
price to each strike (dealer-flow ladder). Built from the signed strike
GEX profile.

Positive at a strike ≈ expected dealer **buying** if spot reaches that
level. Negative ≈ selling.

Default `positioning=flow`. See [Positioning](/concepts/positioning).
