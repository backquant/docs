---
title: "Multi-symbol GEX levels"
openapi: "GET /multi/gex/levels"
description: "GEX levels across multiple symbols (bundled). Multi-symbol GEX levels in one round-trip."
---

Bundled multi-symbol read. Up to 8 symbols per request. Returns
per-symbol entries plus a `served` / `missing` / `invalid` breakdown.

Default **`positioning=flow`** (with the same per-symbol fallbacks as
single-symbol levels). See [Positioning](/concepts/positioning).
