---
title: "Yields"
description: "Retrieve US Treasury yields, yield spreads, and real yield data to track the interest rate environment."
---

All endpoints require an `X-API-Key` header. Responses use the standard envelope — `success`, `data`, and `meta` fields.

<AccordionGroup>
  <Accordion title="GET /macro/treasury-yields">
    Returns the current US Treasury yield curve across standard maturities (1M, 3M, 6M, 1Y, 2Y, 5Y, 10Y, 30Y). Use this to assess the shape of the yield curve and identify steepening or flattening trends that signal shifts in rate expectations.

    ```bash
    curl https://api.backquant.com/v1/macro/treasury-yields \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "1m": 5.28,
        "3m": 5.31,
        "6m": 5.19,
        "1y": 4.97,
        "2y": 4.62,
        "5y": 4.41,
        "10y": 4.35,
        "30y": 4.52
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    Values are annualised yields in percent.
  </Accordion>

  <Accordion title="GET /macro/yield-spread">
    Returns the 2Y–10Y Treasury yield spread — one of the most closely watched recession indicators. A negative value indicates an inverted curve. Use this alongside the 10Y3M spread to monitor credit cycle positioning.

    <ParamField query="smoothing" type="string">
      Optional. Apply smoothing to the spread series. Accepted values: `none` (default), `5d`, `20d`.
    </ParamField>

    ```bash
    curl https://api.backquant.com/v1/macro/yield-spread \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "spread_2y10y": -0.27,
        "yield_2y": 4.62,
        "yield_10y": 4.35,
        "inverted": true
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `spread_2y10y` is expressed in percentage points (10Y minus 2Y).
  </Accordion>

  <Accordion title="GET /macro/yield-spread-10y3m">
    Returns the 10Y–3M Treasury yield spread, the Federal Reserve's preferred recession-probability indicator. This spread has historically inverted 6–18 months before every US recession since 1970. A deeply negative reading indicates elevated near-term recession risk.

    <ParamField query="smoothing" type="string">
      Optional. Apply smoothing to the spread series. Accepted values: `none` (default), `5d`, `20d`.
    </ParamField>

    ```bash
    curl https://api.backquant.com/v1/macro/yield-spread-10y3m \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "spread_10y3m": -0.96,
        "yield_3m": 5.31,
        "yield_10y": 4.35,
        "inverted": true
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `spread_10y3m` is expressed in percentage points (10Y minus 3M).
  </Accordion>

  <Accordion title="GET /macro/real-yields">
    Returns real (inflation-adjusted) Treasury yields, derived by subtracting breakeven inflation rates from nominal yields. Positive real yields represent restrictive financial conditions; negative real yields are historically supportive of risk assets including equities and Bitcoin.

    <ParamField query="tenor" type="string">
      Optional. Tenor to return. Accepted values: `5y`, `10y` (default), `30y`.
    </ParamField>

    ```bash
    curl https://api.backquant.com/v1/macro/real-yields \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "real_yield_5y": 1.92,
        "real_yield_10y": 1.78,
        "real_yield_30y": 1.61,
        "breakeven_5y": 2.49,
        "breakeven_10y": 2.57,
        "breakeven_30y": 2.91
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    All values are in percent. Breakeven inflation is implied from TIPS pricing.
  </Accordion>
</AccordionGroup>
