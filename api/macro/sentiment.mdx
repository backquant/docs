---
title: "Sentiment & cycle"
description: "Track fear, business cycle positioning, cross-asset regime signals, and carry trade conditions to identify where we are in the macro cycle."
---

All endpoints require an `X-API-Key` header. Responses use the standard envelope — `success`, `data`, and `meta` fields.

<AccordionGroup>
  <Accordion title="GET /macro/vix">
    Returns the CBOE Volatility Index (VIX) along with term structure and historical context. The VIX measures the market's 30-day implied volatility expectation for the S&P 500 — readings below 20 indicate complacency, above 30 indicate fear, and above 40 indicate panic. Use the term structure slope to distinguish near-term stress from structural regime shifts.

    ```bash
    curl https://api.backquant.com/v1/macro/vix \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "vix": 14.82,
        "vix9d": 13.41,
        "vix3m": 16.74,
        "vix6m": 17.89,
        "term_structure_slope": "contango",
        "pct_rank_1y": 0.18,
        "regime": "low_vol"
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `pct_rank_1y` is the VIX percentile over the trailing 12 months (0 = calmest). `term_structure_slope` is `contango` (normal), `flat`, or `backwardation` (stressed). `regime` is one of `low_vol`, `elevated`, `stress`, `panic`.
  </Accordion>

  <Accordion title="GET /macro/sentiment">
    Returns a composite market sentiment score aggregating signals from equity positioning, put/call ratios, fund flows, survey data, and cross-asset momentum. Use this to identify extremes in investor positioning that can precede mean-reversion moves.

    <ParamField query="components" type="boolean">
      Optional. Set to `true` to include individual component scores. Defaults to `false`.
    </ParamField>

    ```bash
    curl https://api.backquant.com/v1/macro/sentiment \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "sentiment_score": 68,
        "label": "greed",
        "signal": "cautious",
        "positioning_score": 71,
        "flows_score": 64,
        "survey_score": 69,
        "momentum_score": 72
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `sentiment_score` is 0–100 (0 = extreme fear, 100 = extreme greed). `label` is one of `extreme_fear`, `fear`, `neutral`, `greed`, `extreme_greed`. `signal` is `buy_contrarian`, `neutral`, or `cautious`.
  </Accordion>

  <Accordion title="GET /macro/bci">
    Returns the Business Cycle Indicator (BCI), a leading composite that tracks where the economy sits within the expansion–contraction cycle. The BCI synthesises labour market data, industrial production, credit conditions, and yield curve signals into a single regime score.

    <ParamField query="country" type="string">
      Optional. Country code. Accepted values: `us` (default), `eu`, `global`.
    </ParamField>

    ```bash
    curl https://api.backquant.com/v1/macro/bci \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "bci_score": 54.2,
        "bci_1m_change": 1.4,
        "phase": "expansion",
        "sub_phase": "mid_cycle",
        "momentum": "improving",
        "country": "us"
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `bci_score` is 0–100 (50 = neutral). `phase` is one of `contraction`, `trough`, `recovery`, `expansion`, `peak`. `momentum` is `deteriorating`, `stable`, or `improving`.
  </Accordion>

  <Accordion title="GET /macro/copper-gold">
    Returns the copper-to-gold ratio, a cross-asset signal that proxies global growth expectations relative to safe-haven demand. Rising copper/gold indicates markets are pricing in stronger industrial demand and tends to correlate with higher bond yields and risk-on positioning. Use it as a real-time growth sentiment proxy.

    <ParamField query="lookback" type="string">
      Optional. Lookback period for momentum calculation. Accepted values: `1m` (default), `3m`, `6m`.
    </ParamField>

    ```bash
    curl https://api.backquant.com/v1/macro/copper-gold \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "ratio": 0.000491,
        "copper_price_usd": 3.87,
        "gold_price_usd": 2048.30,
        "ratio_3m_change_pct": 4.2,
        "trend": "rising",
        "implied_10y_yield": 4.28,
        "signal": "growth_positive"
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `copper_price_usd` is per pound; `gold_price_usd` is per troy ounce. `implied_10y_yield` is the 10Y Treasury yield implied by the historical relationship between the ratio and rates.
  </Accordion>

  <Accordion title="GET /macro/quadrant">
    Returns the current macro regime quadrant based on growth and inflation dynamics. The four quadrants — Goldilocks, Reflation, Stagflation, and Deflation — determine which asset classes historically outperform. Use this to align your portfolio construction with the prevailing macro regime.

    ```bash
    curl https://api.backquant.com/v1/macro/quadrant \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "quadrant": "goldilocks",
        "growth_momentum": "positive",
        "inflation_momentum": "negative",
        "growth_score": 58,
        "inflation_score": 38,
        "quadrant_duration_days": 47,
        "preferred_assets": ["equities", "credit", "bitcoin"],
        "avoid": ["commodities", "tips"]
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `quadrant` is one of `goldilocks` (growth up, inflation down), `reflation` (growth up, inflation up), `stagflation` (growth down, inflation up), or `deflation` (growth down, inflation down).
  </Accordion>

  <Accordion title="GET /macro/yen-carry">
    Returns indicators for the Japanese yen carry trade — one of the largest positioning dynamics in global macro. When the carry trade unwinds, the yen strengthens sharply and risk assets sell off globally. This endpoint tracks USDJPY, BoJ policy divergence, and estimated carry trade positioning stress.

    ```bash
    curl https://api.backquant.com/v1/macro/yen-carry \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```

    **Response**

    ```json
    {
      "success": true,
      "data": {
        "usdjpy": 148.62,
        "usdjpy_1m_change_pct": -1.4,
        "carry_yield_differential_pct": 5.21,
        "positioning_stress": "low",
        "unwind_risk": "moderate",
        "boj_rate_pct": 0.10,
        "fed_rate_pct": 5.33,
        "signal": "watch"
      },
      "meta": {
        "timestamp": "2024-01-15T16:00:00Z",
        "version": "1.0"
      }
    }
    ```

    `positioning_stress` is `low`, `moderate`, or `high`. `unwind_risk` is `low`, `moderate`, or `high`. `signal` is `stable`, `watch`, or `unwind_risk`.
  </Accordion>
</AccordionGroup>
