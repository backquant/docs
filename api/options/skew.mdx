---
title: "Options Skew"
description: "Retrieve the put/call implied volatility differential across strikes for a given asset and expiry."
---

The skew endpoint returns implied volatility as a function of strike (or delta), letting you measure the difference in demand between out-of-the-money puts and calls. Positive skew — where downside puts carry higher IV than upside calls — signals that the market is paying a premium for downside protection. Negative skew (call skew) is common during speculative rallies when demand for upside calls outpaces put buying.

Traders use skew to gauge directional sentiment, identify asymmetric hedging opportunities, and assess whether risk reversals are priced in their favor.

<Tip>
Skew tells you what the options market fears most. Persistent put skew above historical norms can precede de-risking in spot markets; elevated call skew often coincides with retail-driven FOMO rallies.
</Tip>

## Endpoint

```
GET https://api.backquant.com/v1/options/skew
```

## Query parameters

<ParamField query="symbol" type="string" required>
  The asset to query. Supported values: `BTC`, `ETH`.
</ParamField>

<ParamField query="expiry" type="string">
  Expiry date in `YYYY-MM-DD` format. If omitted, the nearest available expiry is returned.
</ParamField>

<ParamField query="delta_range" type="string" default="25">
  Delta level for the skew measurement. Common values: `10`, `25`. Represents the absolute delta (e.g. `25` = 25-delta options).
</ParamField>

## Request example

```bash
curl "https://api.backquant.com/v1/options/skew?symbol=BTC&expiry=2024-05-31&delta_range=25" \
  -H "X-API-Key: bq_live_your_api_key_here"
```

## Response fields

<ResponseField name="success" type="boolean" required>
  `true` when the request succeeds.
</ResponseField>

<ResponseField name="data" type="object" required>
  <Expandable title="properties" defaultOpen>
    <ResponseField name="symbol" type="string">
      Asset symbol, e.g. `BTC`.
    </ResponseField>
    <ResponseField name="expiry" type="string">
      Expiry date used for this skew snapshot.
    </ResponseField>
    <ResponseField name="dte" type="number">
      Days to expiry at the time of the snapshot.
    </ResponseField>
    <ResponseField name="skew" type="object[]">
      Array of IV values across strikes, ordered by strike ascending.
      <Expandable title="properties">
        <ResponseField name="strike" type="number">
          Strike price in USD.
        </ResponseField>
        <ResponseField name="delta" type="number">
          Option delta at this strike (negative for puts, positive for calls).
        </ResponseField>
        <ResponseField name="iv" type="number">
          Implied volatility at this strike as a decimal.
        </ResponseField>
        <ResponseField name="option_type" type="string">
          `call` or `put`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="skew_25d" type="number">
      25-delta risk reversal: 25d put IV minus 25d call IV. Positive values indicate put skew (downside premium).
    </ResponseField>
    <ResponseField name="skew_10d" type="number">
      10-delta risk reversal: 10d put IV minus 10d call IV.
    </ResponseField>
    <ResponseField name="atm_iv" type="number">
      At-the-money implied volatility for this expiry.
    </ResponseField>
    <ResponseField name="spot" type="number">
      Spot price at the time of snapshot.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  <Expandable title="properties">
    <ResponseField name="timestamp" type="string">
      ISO 8601 timestamp of when the snapshot was taken.
    </ResponseField>
    <ResponseField name="version" type="string">
      API version string, e.g. `1.0`.
    </ResponseField>
  </Expandable>
</ResponseField>

<Note>
`skew_25d` is the most widely quoted skew metric. A value of `0.06` means 25-delta puts are pricing 6 volatility points above 25-delta calls — indicating a moderate downside premium. Crypto often shows elevated put skew relative to equities during drawdown regimes.
</Note>
