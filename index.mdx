## Get started in 3 steps

<Steps>
  <Step title="Get your API key">
    Sign in to the [BackQuant Dashboard](https://backquant.com/dashboard) and copy your API key.
  </Step>
  <Step title="Make your first request">
    Pass your key in the `X-API-Key` header and call any endpoint.

    ```bash
    curl https://api.backquant.com/v1/gex/levels \
      -H "X-API-Key: bq_live_your_api_key_here"
    ```
  </Step>
  <Step title="Explore the data">
    Browse the [API Reference](/api/gex/strike-profile) to discover all available endpoints.
  </Step>
</Steps>
